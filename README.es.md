# Cursor Usage Menubar (Español)

App nativa de macOS para ver el **uso de API de Cursor** en la barra de menú — especialmente cuánto cupo **queda** para modelos named (GPT, Claude, Opus).

Documentación principal en inglés: [README.md](README.md).

## Formato menu bar

`52% | 7/16` — API **restante** % | Auto+Composer usado / Total usado

## Instalación

```bash
./scripts/install.sh
open ~/Applications/Cursor\ Usage\ Menubar.app
```

Activa "Iniciar con el sistema" desde **Ajustes** en el popover.

## Privacidad

Solo lee tu token local de Cursor y consulta `cursor.com` / `api2.cursor.sh`. Ver [PRIVACY.md](PRIVACY.md).
